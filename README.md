### Hi there, I'm Katie Wampler!

- Research Associate at [Oregon State University](https://oregonstate.edu/) in the [Forest Ecohydrology and Watershed Science Lab](https://fews.forestry.oregonstate.edu/).
- Researcher and Data Manager on the [Wildfire and Water Security](https://wws.forestry.oregonstate.edu/) project.

## Software Projects

- [eemanalyzeR](https://katiewampler.github.io/eemanalyzeR/index.html): A **stable** R package providing tools for processing and analyzing raw excitation-emission matrices (EEMs) data. It includes functions for data cleaning, calculation of fluorescence and absorbance indices, and generating visualizations.
- [SondePolishR](https://wildfire-water-security.github.io/WWS-Node1-SondePolishR-sonde-qaqc/): An *in-development* Shiny app and R package to aid in manually correcting water quality sonde data.
